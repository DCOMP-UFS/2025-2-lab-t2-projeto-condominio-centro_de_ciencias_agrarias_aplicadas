# Dados Compartilhados do Centro

Esta pasta contém dados compartilhados entre todos os laboratórios do Centro de Ciências Agrárias Aplicadas.

## Estrutura Sugerida

```
dados-centro/
├── publicacoes/       # Artigos e publicações científicas
├── datasets/          # Conjuntos de dados de pesquisas
├── relatorios/        # Relatórios anuais e trimestrais
├── imagens/           # Imagens e recursos visuais
└── documentos/        # Documentos administrativos
```

## Acesso

Todos os laboratórios têm acesso de leitura a esta pasta através de volumes Docker compartilhados.

Para acessar via web, use: `http://localhost/dados`
